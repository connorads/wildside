# Weather / Environment Fidelity Audit

Adversarially-verified audit of the Kid Chameleon source-port's **weather / environment-effects** subsystem (`weather.rs`, with `level.rs` palette-rotate objects, `lib.rs` per-frame step, `boot.rs`), comparing the live path to the `kid.asm` `Init_SpecialEffects` / `sub_6034` / `sub_61CA` / `Obj_Lava_Geyser` / `Murderwall` routines. It goes deeper than the level-loading audit's "only weather 1 is handled" finding, into the per-frame correctness of what *is* wired and the storm script-machine fidelity.

The recurring failure mode is the same one the other audits found crate-wide: **ASM-faithful pure helpers exist and are unit-tested, but carry `#[cfg_attr(not(test), allow(dead_code))]` (or `#[allow(dead_code)]`) and are never called from the live path.** Weather has been improving, but several renderer-facing traces still follow this pattern: faithful model code exists, while the live runtime or renderer still uses a parallel approximation.

Findings worth foregrounding:

- **`Init_SpecialEffects` is partially wired.** The ROM indexes 5 init routines by `Level_Special_Effects-1` (1=Lava, 2=Storm, 3=Storm+Hail, 4=Unknown, 5=Nothing, `kid.asm:27461-27476`). Native `init_weather` now handles Lava, the Storm/Storm+Hail state/palette/art-upload records, and the weather-4 Unknown loc_14DF6/loc_14E42 upload records. Renderer consumption of the storm and Unknown plane uploads remains open.

- **The per-frame storm machine (`sub_6034 → sub_6048`) is partially live.** It drives the 20s storm palette fade, the 25s Mountain thunder SFX/flash, and the 35s snow/hail gates (`kid.asm:6032-6184`). Live `step_weather` now dispatches weather 2/3 through the faithful `step_level_special_effects_sub_6048`, applies the storm fade palette ops, consumes the `sub_14C0` blend, and drives the 5-slot `sub_61CA` falling-weather worker for storm+hail. The remaining storm gap is renderer consumption of the recorded storm plane/pattern upload.

- **Storm hail's worker state and direct sprites are live.** The live path now drives `step_weather_worker_sub_61CA` with ROM random bytes, raw collision rows, five falling slots, ten impact slots, and the Kid `$28` push-timer. Current traces also expose the worker's loc_63C4/loc_6462 sprite words, and native-player renders those words from the loc_14CCE/loc_14CD8 weather art upload instead of relying on the compatibility hail-projectile projection.

- **The lava-geyser eruption no longer uses the old 4px pixel ramp.** Fixed candidate 2026-06-15: live `step_lava_geysers` now maps encoded height to 16px sprite rows, uses `$48=2` rise cadence, `$50=$1E` counted through 6-frame top cycles, and one-row collapse from `Obj_Lava_Geyser` (`kid.asm:27908-28035`). Remaining lava-geyser gaps are the script-walk intro/disable sentinels, art upload, and renderer window details listed below.

- **Palette animation is only partially live.** Fixed candidate 2026-06-15: level entry now spawns and ticks Island shore `loc_1202A` plus `RotatePalette_Lava_Water`, and the lava/water worker mutates the runtime `Palette_Buffer+$E..+$14` on the ROM cadence. Follow-up 2026-06-16: lava weather now seeds `Pal_7B8AC` into runtime `Palette_Buffer+$20`, ticks `Animation_Geyser loc_14B2A`, rotates runtime `Palette_Buffer+$28..+$2E` every five lava frames, and native-player loc_14BE8 lava sprites consume those live trace words. Follow-up 2026-06-17: native-player also consumes the Island shore frame tuple and patches the `$F600/$F6C0/$F760` Scroll B window from generated shore art. Remaining gaps: broader level-load/theme palette initialisation and typed Island shore VRAM/source-label provenance.

Murderwall is the best-wired unit: its init and per-frame motion are faithful and live; only the 16.16 initial-X fraction still diverges.
